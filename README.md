# COM Port Overlay

Небольшая панель для Windows, которая показывает выбранные COM-порты одной строкой над часами.

## Возможности

- Автоматически скрывает панель в системный трей, если нет портов, отмеченных для показа.
- Возвращает панель, когда появляется отображаемый COM-порт.
- Позволяет скрывать отдельные порты в настройках.
- Поддерживает запуск при входе в Windows.
- Показывает значок в системном трее с меню настроек, показа панели и выхода.

## Запуск

Запустите `ComPortOverlay.exe`. Для работы требуется .NET Framework 4.x.

Кнопка с шестерёнкой открывает настройки. Отметьте галочкой порт, который нужно скрыть. Настройка запуска при входе в Windows находится в том же окне.

## Сборка из исходного кода

Скомпилируйте `ComPortOverlay.cs` как Windows-приложение, подключив сборки `System`, `System.Drawing`, `System.Windows.Forms` и `System.Management`. Сборка использует только стандартные компоненты .NET Framework.
